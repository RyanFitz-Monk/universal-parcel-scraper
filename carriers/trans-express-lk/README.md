# Trans Express

Trans Express parcels use enabled universal providers. There is no dedicated adapter.

Trans Express is a Sri Lankan courier in Colombo that delivers across the island and collects cash
on delivery.

## Numbers

Its tracker takes a waybill number, for cash-on-delivery or domestic parcels. No public page shows a
Trans Express number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The tracker reads no number from its address, so there are no tracking links.
