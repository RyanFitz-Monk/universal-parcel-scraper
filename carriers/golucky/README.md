# GoLucky Express

GoLucky Express parcels use enabled universal providers. There is no dedicated adapter.

GoLucky (喜运达, 深圳喜运达供应链科技有限公司) is a cross-border operator based in Hangzhou with a
Shenzhen branch. It runs air, sea and land lines and overseas warehouses for Southeast Asia and
Latin America.

## Numbers

No public page shows a GoLucky number, so there is no rule.

## Why there is no adapter

The tracker posts numbers to `erp.goluckyvip.com/ems/api/shipment/routes` with an Alibaba Cloud
CAPTCHA token, and no public number is known to check its replies against.

## Links

The tracker takes numbers only in its form, so the catalog sends people to the tracking page.
