# Mira Transportes

Mira Transportes parcels use enabled universal providers. There is no dedicated adapter.

Mira Transportes is a São Paulo road carrier with more than 900 vehicles. It carries part and full
loads between the South and Southeast and Brazil's Centre-West and North.

## Numbers

Its tracker takes a CPF or CNPJ and lists that person's or company's shipments. It has no field for
a Mira number, so there is no rule.

## Why there is no adapter

Every lookup needs a CPF or CNPJ.

## Links

Lookups need the tax id, so there are no tracking links.
