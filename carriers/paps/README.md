# Paps

Paps parcels use enabled universal providers. There is no dedicated adapter.

Paps is a delivery and e-commerce logistics company in Dakar that delivers in Senegal and Côte
d'Ivoire.

## Numbers

Its tracker takes the order's id. No public page shows a Paps number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`papslogistics.com/tracking/?uid=<number>` looks one order up, and the library reads the number from
that address.
