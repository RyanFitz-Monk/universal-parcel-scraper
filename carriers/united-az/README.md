# United.az

United.az parcels use enabled universal providers. There is no dedicated adapter.

United.az is a Baku shipping company that forwards online orders into Azerbaijan. It merged the
forwarders Expargo, Kargolux, Kango, Morex, 166 Cargo and Findex.

## Numbers

Its tracker takes its own tracking code. No public page shows a United.az code, so there is no rule.

## Why there is no adapter

Its tracker names the company that delivers the last leg. No public number is known to check its
tracker's replies against.

## Links

`cui.united.az/tracking-code?trackingCode=<code>` looks one code up, and the library reads the code
from that address.
