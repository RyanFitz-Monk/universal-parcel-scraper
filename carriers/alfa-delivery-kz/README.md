# Alfa Delivery Services

Alfa Delivery Services parcels use enabled universal providers. There is no dedicated adapter.

Alfa Delivery Services is a courier in Almaty, Kazakhstan, and UPS's service partner there.

## Numbers

Its tracker takes its own waybill numbers. Shipments it sends abroad with UPS carry UPS numbers,
which [UPS](../ups/README.md) tracks. No public page shows an Alfa Delivery Services waybill, so
there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The tracking box on the home page answers in a pop-up, so there are no tracking links.
