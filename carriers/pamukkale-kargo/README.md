# Pamukkale Kargo

Pamukkale Kargo parcels use enabled universal providers. There is no dedicated adapter.

Pamukkale Kargo is the parcel service of the Turkish coach company Pamukkale Turizm, founded in
2013. It carries parcels between towns on the coach network.

## Numbers

The tracker takes a number of up to ten digits. No public page shows one, so there is no rule.

## Why there is no adapter

The tracker asks for the sender's or recipient's phone number beside the tracking number and
posts both in an Oracle APEX form.

## Links

The tracker takes numbers only in its form, so the catalog sends people to the tracking page.
