# Fardar Express Domestic

Fardar Express Domestic parcels use enabled universal providers. There is no dedicated adapter.

Fardar Express Domestic is a Sri Lankan courier with branches in all twenty-five districts, set up
with the Chinese courier Fardar International.

## Numbers

Its tracker takes a tracking or waybill id. No public page shows a Fardar Express Domestic number,
so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The tracking box on the home page posts the number and shows the answer in a pop-up, so there are no
tracking links.
