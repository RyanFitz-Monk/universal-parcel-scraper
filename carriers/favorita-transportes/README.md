# Favorita Transportes

Favorita Transportes parcels use enabled universal providers. There is no dedicated adapter.

Favorita Transportes is a road carrier in Jandira, São Paulo. It collects in São Paulo, Espírito
Santo, Goiás, the Federal District and Santa Catarina, and delivers across Brazil's Centre-West and
North.

## Numbers

Its tracker takes a CPF or CNPJ and lists that person's or company's shipments. It has no field for
a Favorita number, so there is no rule.

## Why there is no adapter

Every lookup needs a CPF or CNPJ.

## Links

Lookups need the tax id, so there are no tracking links.
