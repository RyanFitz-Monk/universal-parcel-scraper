# MRW Venezuela

MRW Venezuela parcels use enabled universal providers. There is no dedicated adapter.

MRW Venezuela is a Venezuelan courier with agencies across the country. It has its own tracker and
numbers, apart from Spain's [MRW](../mrw/README.md).

## Numbers

Its tracker takes ten to forty-five characters. No public page shows an MRW Venezuela number, so
there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The tracking box on the home page posts the number, so there are no tracking links.
