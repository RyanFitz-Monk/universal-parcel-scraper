# Mahex

Mahex parcels use enabled universal providers. There is no dedicated adapter.

Mahex is an Iranian express courier based in Tehran, for city, intercity and cash-on-delivery
parcels.

## Numbers

Its tracker takes a consignment number. No public page shows a Mahex number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The tracking form looks the number up and answers on the same page, so there are no tracking links.
