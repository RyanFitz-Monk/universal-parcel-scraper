# Conwest Logistics

Conwest Logistics parcels use enabled universal providers. There is no dedicated adapter.

Conwest Logistics GmbH, of Aachen, handles cross-border e-commerce: relabelling, warehousing,
customs, trucking, groupage and express parcels in Germany, Belgium and Poland.

## Numbers

The tracking box on its home page takes up to fifty parcel numbers or track IDs. No public page
shows one, so there is no rule.

## Why there is no adapter

The box posts the numbers to a JSON interface and shows the answer in the page, so no address
opens a parcel. No public number is known to check its tracker's replies against.
