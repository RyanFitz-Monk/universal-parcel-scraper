# ABC Cargo Express

ABC Cargo Express parcels use enabled universal providers. There is no dedicated adapter.

ABC Cargo Express is the parcel service of ABC Transport, a Nigerian intercity coach operator.
Parcels travel between its hubs.

## Numbers

Its tracker takes a six-character waybill code. Such a code is too short to tell apart from other
carriers' numbers, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The tracking box on the home page looks the code up in place, so there are no tracking links.
