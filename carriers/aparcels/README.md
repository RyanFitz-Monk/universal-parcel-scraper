# AParcels

AParcels parcels use enabled universal providers. There is no dedicated adapter.

AParcels is a tracking service for online sellers, not a carrier. It gives buyers its own APX
numbers, which only its page tracks, and shows the carrier's scans behind them.

## Numbers

Its home page says its numbers are `APX` followed by twelve digits. No public page shows one,
so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`aparcels.com/track/<number>` opens one number, and the library reads the number from that
address.
