# M5 Continent

M5 Continent parcels use enabled universal providers. There is no dedicated adapter.

M 5 Continent Logistics Solution (P) Ltd., of New Delhi, ships Indian online sellers' orders abroad
and handles express, air and sea freight, personal baggage and overseas warehousing. Its site is
m5clogs.com.

## Numbers

Its tracking box takes an order ID or an air waybill number. No public page shows one, so there is
no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The tracking page posts the number back to itself in an ASP.NET form, so no address opens one
shipment.
