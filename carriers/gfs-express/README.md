# GFS Express

GFS Express parcels use enabled universal providers. There is no dedicated adapter.

GFS Express delivers online orders and collects cash on delivery in the Gulf, Saudi Arabia and
Kuwait among them, mostly for Chinese brands.

## Numbers

No public page shows a GFS Express number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`track.gfsxpress.com/#/track-order?trackingStr=<number>` looks one number up, and the library reads
the number from that address.
