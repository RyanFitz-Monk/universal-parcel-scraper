# T.M.G

T.M.G parcels use enabled universal providers. There is no dedicated adapter.

T.M.G Co., Ltd. (株式会社T.M.G), of Ibaraki, Osaka, delivers e-commerce parcels over the last mile
and runs logistics centres in Settsu.

## Numbers

The tracker takes numbers of up to twelve characters, ten at a time. No public page shows one, so
there is no rule.

## Why there is no adapter

The tracker is a Shift_JIS form that posts `inputData[<n>].inq_no` within a server session. No
public number is known to check its replies against.

## Links

The tracker takes numbers only in a form post, so the catalog sends people to the tracking page.
