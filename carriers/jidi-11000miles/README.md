# 11000Miles

11000Miles parcels use enabled universal providers. There is no dedicated adapter.

11000Miles is the brand of Jidi International Logistics (Shenzhen), a cross-border forwarder with
lines to Europe and the United States, European trucking and last-mile delivery.

## Numbers

Its tracking box takes order numbers. No public page shows one, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The tracking box on 11000miles.com opens its company's page on the Intelink OMS platform,
`mms.intelink.net.cn/oms/#/logisticsTracking?companyId=10355&nos=<number>`. Other forwarders
use the same platform and only the company id names 11000Miles, so no link rule reads it.
