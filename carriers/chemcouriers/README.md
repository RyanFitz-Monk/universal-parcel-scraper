# Chemcouriers

Chemcouriers shipments use enabled universal providers. There is no dedicated adapter.

Chemcouriers carries packaged chemicals, hazardous materials and dangerous goods across New Zealand
and Australia. It is a unit of the Mainfreight Group with its own tracking page, which takes the
same query as [Mainfreight's](../mainfreight/README.md). Its site is chemcouriers.com.

## Numbers

Its tracker takes a reference number. No public page shows one, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against, or to show whether Mainfreight's
tracker answers the same references.

## Links

The tracking box opens `www.chemcouriers.com/tracking?trackingnumber=<number>`, and the library
reads the number from `trackingnumber`.
