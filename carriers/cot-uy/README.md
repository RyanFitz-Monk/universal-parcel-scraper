# COT Encomiendas

COT Encomiendas parcels use enabled universal providers. There is no dedicated adapter.

COT Encomiendas carries envelopes and parcels on the COT bus lines between Colonia, Montevideo,
Maldonado and Rocha.

## Numbers

Its tracker's example starts with COTEX. No public page shows a COT number, so there is no rule.

## Why there is no adapter

The tracker posts the number with a reCAPTCHA answer. No public number is known to check its
tracker's replies against.

## Links

The tracking form posts its field, so there are no tracking links.
