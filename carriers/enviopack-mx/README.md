# Envíopack México

Envíopack México parcels use enabled universal providers. There is no dedicated adapter.

Envíopack México is the Mexican operation of the Argentine logistics operator Envíopack
(`enviopack-ar`): fulfilment, last-mile delivery and national transport. Its tracker runs on a
backend of its own, `api-mx.enviopack.com`.

## Numbers

No public page shows an Envíopack México number, so there is no rule.

## Why there is no adapter

No public number is known to check the tracker's replies against.

## Links

The tracker takes the number as its path, so `tracking.enviopack.com.mx/<number>` opens one
shipment.
