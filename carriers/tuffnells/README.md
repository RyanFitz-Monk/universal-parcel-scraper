# Tuffnells

Tuffnells parcels use enabled universal providers. There is no dedicated adapter.

Tuffnells, a trading name of TF Trading Limited, collects and delivers bulky, heavy and awkward
parcels for UK businesses. It is a separate company from Tuffnells Parcels Express, which went
into administration, and its tracker does not serve that company's numbers.

## Numbers

Its tracker's example is `TN` and ten digits. No public page shows a number, so there is no
rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`tuffnells.co.uk/track/<number>` opens one parcel, and the library reads the number from that
address.
