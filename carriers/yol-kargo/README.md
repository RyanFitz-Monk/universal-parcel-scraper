# Yol Kargo

Yol Kargo parcels use enabled universal providers. There is no dedicated adapter.

Yol Kargo is a Turkish parcel carrier licensed by BTK, with branches and agencies and its own
fleet in Istanbul. yolkargo.com is not its site.

## Numbers

No public page shows a Yol Kargo number, so there is no rule.

## Why there is no adapter

The tracking form opens `kargo.php?q=<number>`. No public number is known to check its replies
against.

## Links

The catalog reads the number from `q` on `yolkargo.com.tr/kargo.php`.
