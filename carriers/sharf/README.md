# Sharf

Sharf parcels use enabled universal providers. There is no dedicated adapter.

Sharf, formerly Scharff, is a Peruvian logistics company founded in 1985. It runs domestic courier
delivery with parcel points, warehousing and customs clearance from Lima.

## Numbers

Its tracker takes codes of up to fourteen characters. No public page shows a Sharf number, so there
is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`envia.holasharf.com/tracking/<number>` opens one shipment, and the library reads the number from
that address.
