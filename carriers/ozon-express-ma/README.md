# Ozon Express

Ozon Express parcels use enabled universal providers. There is no dedicated adapter.

Ozon Express is a Moroccan courier for online sellers. It is unrelated to Russia's
[Ozon](../ozon-logistics/README.md).

## Numbers

Its site's example is three letters, nine digits and two letters. No public page shows an Ozon
Express number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`ozonexpress.ma/tracking-colis/<number>` opens one parcel, and the library reads the number from
that address. The search page is the tracking box on the home page.
