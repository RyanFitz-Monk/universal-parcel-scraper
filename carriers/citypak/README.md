# Citypak

Citypak parcels use enabled universal providers. There is no dedicated adapter.

Citypak is a Sri Lankan courier with branches across the island.

## Numbers

No public page shows a Citypak number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`track.citypak.lk/track?tracking_number=<number>` looks one number up, and the library reads the
number from that address.
