# Janani Express

Janani Express parcels use enabled universal providers. There is no dedicated adapter.

Janani Express is a Bangladeshi courier and parcel service.

## Numbers

Its tracker takes a CN number with the year it was booked. No public page shows a Janani Express
number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`jananiexpress.com/tracking?cn=<number>` looks one number up, and the library reads the number from
that address. A parcel booked in an earlier year needs its year chosen on the page.
