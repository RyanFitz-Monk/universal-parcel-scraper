# Tipax

Tipax parcels use enabled universal providers. There is no dedicated adapter.

Tipax is Iran's oldest private courier, based in Tehran, with a nationwide network of agencies.

## Numbers

Its tracker takes a barcode, order or contract number. No public page shows a Tipax number, so there
is no rule.

## Why there is no adapter

The tracking form carries an image CAPTCHA and asks whether you are the sender or the recipient. No
public number is known to check its tracker's replies against.

## Links

The tracker posts the number and shows the answer on the same page, so there are no tracking links.
