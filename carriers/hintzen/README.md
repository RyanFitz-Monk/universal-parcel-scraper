# Hintzen Logistik

Hintzen Logistik parcels use enabled universal providers. There is no dedicated adapter.

Hintzen Logistik GmbH, of Eschweiler, carries general cargo, part and full loads, and is a member
of the VTL and ILN networks.

## Numbers

Its tracker takes an order number of up to 35 characters with the recipient's postcode. No
public page shows one, so there is no rule.

## Why there is no adapter

Every lookup needs the recipient's postcode, and the tracker is an ASP.NET form that posts it with
the page's state. No public number is known to check its tracker's replies against.
