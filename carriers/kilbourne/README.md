# Kilbourne

Kilbourne parcels use enabled universal providers. There is no dedicated adapter.

Kilbourne is a courier in Las Rozas de Madrid for same-day collections and deliveries in the
Comunidad de Madrid, with e-commerce storage, picking and packing. Its national parcels go
through [GLS](../gls-es/README.md).

## Numbers

No public page shows a Kilbourne number, so there is no rule.

## Why there is no adapter

The tracker is the company's tenant of the IRIS courier software on `kilbourne.factapp.es`. It
posts an ASP.NET form, so a number cannot go in the address. No public number is known to check
its replies against.

## Links

The tracker takes numbers only in its form, so the catalog sends people to the tracking page.
