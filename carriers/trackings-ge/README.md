# Trackings.GE

Trackings.GE parcels use enabled universal providers. There is no dedicated adapter.

Trackings.GE is a Tbilisi courier that delivers across Georgia and runs pickup points.

## Numbers

The examples in its developer documentation are fifteen digits. No public page shows a real
Trackings.GE number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`trackings.ge/en/track?track_num=<number>` looks one number up (also under `/ka/` and `/ru/`), and
the library reads the number from that address.
