# PDS Direct

PDS Direct parcels use enabled universal providers. There is no dedicated adapter.

PDS Direct, of Oldbury in the West Midlands, delivers fragile and large items with two-person
crews across the UK and Ireland, and runs warehousing.

## Numbers

Its tracker takes a reference. No public page shows one, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`webportal.pdsdirect.co.uk/tracktrace?reference=<reference>` opens one delivery, and the
library reads the reference from `reference`.
