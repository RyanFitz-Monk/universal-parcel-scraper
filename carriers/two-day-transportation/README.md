# 2 Day Transportation

2 Day Transportation shipments use enabled universal providers. There is no dedicated adapter.

2 Day Transportation is a less-than-truckload carrier whose team drivers run between metro New
York and New Jersey and South Florida, from terminals in Belleville, New Jersey and Hialeah,
Florida. It also serves New England, Pennsylvania, Delaware, upstate New York, Chicago, Texas and
California.

## Numbers

The trace box on its home page takes a PRO number of up to twelve characters. No public page shows
one, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The trace box opens
`www.2daytranspo.com/admin/code/PopUp/PopUp_ShippingTrackingItem.aspx?ProNumber=<number>` in a
pop-up, and the library reads the number from `ProNumber`.
