# Turbo

Turbo parcels use enabled universal providers. There is no dedicated adapter.

Turbo is an Egyptian courier for online shops, with about seventy branches across Egypt.

## Numbers

No public page shows a Turbo number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`turbo.info/en/track/<number>` (or `/ar/track/<number>`) opens one shipment, and the library reads
the number from that address.
