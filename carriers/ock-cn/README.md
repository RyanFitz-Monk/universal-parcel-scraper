# OCK

OCK parcels use enabled universal providers. There is no dedicated adapter.

OCK (ONE CLICK, 触达物流, 触达物流科技（深圳）有限公司) is a Shenzhen cross-border operator of small-parcel lines
for goods that other lines refuse (特货), to Canada, the United States, Europe and Australia.

## Numbers

No public page shows an OCK number, so there is no rule.

## Why there is no adapter

The tracker posts up to ten numbers to `query.php`, signed with values the page sets on each load.
No public number is known to check its replies against.

## Links

The tracker takes numbers only in its form, so the catalog sends people to the tracking page.
