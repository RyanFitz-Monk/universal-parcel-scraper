# Xalq Global

Xalq Global parcels use enabled universal providers. There is no dedicated adapter.

Xalq Global forwards parcels into Uzbekistan from the United States, China, Europe, the United Arab
Emirates, Russia and Kazakhstan.

## Numbers

No public page shows a Xalq Global number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The tracking box on the home page answers in place, so there are no tracking links.
