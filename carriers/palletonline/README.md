# PalletOnline

PalletOnline parcels use enabled universal providers. There is no dedicated adapter.

PalletOnline, a division of Browns Distribution Services of Stoke-on-Trent, books pallets online
and moves them on the Palletline network from its own depot.

## Numbers

Its help page says an order ID is a letter for the service followed by digits. No public page
shows one, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`palletonline.co.uk/track?tn=<order ID>` opens one order, and the library reads the order ID
from `tn`.
