# Trusk

Trusk parcels use enabled universal providers. There is no dedicated adapter.

Trusk, of Saint-Ouen, delivers and installs items over 30 kg for online shops and retailers
across France, with independent transport partners.

## Numbers

Its order page shows an order number. No public page shows one, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`track.trusk.com/<language>/<order>` opens one order, and the library reads the order from that
address. The tracker has no search box, so an order opens only from its link.
