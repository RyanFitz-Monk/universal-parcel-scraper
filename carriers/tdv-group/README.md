# TDV Group

TDV Group parcels use enabled universal providers. There is no dedicated adapter.

TDV Group, of Valado dos Frades in Portugal, carries road freight to the rest of Europe and the
UK, parcels, air and sea freight, and distributes in Portugal from its hubs.

## Numbers

Its tracker takes a shipment reference. No public page shows one, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`portal.tdv-group.com/tracktrace/<reference>` looks one shipment up, and the library reads the
reference from that address.
