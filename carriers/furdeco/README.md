# Furdeco

Furdeco parcels use enabled universal providers. There is no dedicated adapter.

Furdeco, of Bloxwich in Walsall, delivers furniture and large items for retailers across the UK
with two-person crews, and assembles and installs them.

## Numbers

Its tracker takes an order number with the delivery postcode. No public page shows an order
number, so there is no rule.

## Why there is no adapter

Every lookup needs the delivery postcode. No public number is known to check its tracker's
replies against.
