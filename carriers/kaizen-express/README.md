# Kaizen Express

Kaizen Express parcels use enabled universal providers. There is no dedicated adapter.

Kaizen Express is a parcel courier in Valdemoro, Madrid, for small businesses and online shops,
with deliveries across Spain and to the rest of Europe.

## Numbers

No public page shows a Kaizen Express number, so there is no rule.

## Why there is no adapter

The tracker posts a form. It takes the tracking code alone, the shipment number with the delivery
postcode, or the client code with a reference. No public number is known to check its replies
against.

## Links

The tracker takes numbers only in its form, so the catalog sends people to the tracking page.
