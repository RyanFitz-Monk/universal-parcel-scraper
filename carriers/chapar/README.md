# Chapar

Chapar parcels use enabled universal providers. There is no dedicated adapter.

Chapar is an Iranian express courier based in Tehran, with more than 450 agents for domestic and
international parcels.

## Numbers

Its tracker takes digits only. No public page shows a Chapar number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`chaparnet.com/track/<number>` opens one shipment, and the library reads the number from that
address.
