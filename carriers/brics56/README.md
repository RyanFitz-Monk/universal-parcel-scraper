# Brics56

Brics56 parcels use enabled universal providers. There is no dedicated adapter.

Brics56 (金专特快, 深圳市金专特快物流有限公司) is a Shenzhen cross-border line from China to Brazil:
direct flights, duties paid and Brazilian last-mile partners. Its site is in Chinese and Portuguese.

## Numbers

No public page shows a Brics56 number, so there is no rule.

## Why there is no adapter

No public number is known to check the tracker's replies against.

## Leads

The tracking page reads `GET /api/peex.php?lang=cn&no=<number>` on the site, which relays the 3PE
Express ERP behind it.

## Links

The tracking page reads numbers from its `no` parameter.
