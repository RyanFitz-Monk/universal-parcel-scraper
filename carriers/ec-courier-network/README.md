# EC Express Courier Network

EC Express Courier Network parcels use enabled universal providers. There is no dedicated adapter.

EC Express Courier Network, or EC Network after its site ecnetwork.co.uk, is a UK courier run by
EC Express Courier Network Ltd of Ilford. It sells ParcelShop, doorstep, same-day and
international deliveries.

## Numbers

Its tracker takes an order number and shows only a placeholder as an example. No public page
shows a number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`ecnetwork.co.uk/order-list/<number>` opens one order, and the library reads the number from
that address.
