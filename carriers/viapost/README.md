# Viapost

Viapost parcels use enabled universal providers. There is no dedicated adapter.

Viapost (ВИА ПОСТ) of Skopje is a courier in North Macedonia, separate from the national post.
Recipients get a tracking link by Viber or text message.

## Numbers

Its tracking box takes the order number. No public page shows one, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`www.viapost.solutions/Order/Track/<number>` opens one order, and the library reads the number
from that address. The tracking box on `viapost.com.mk` sends visitors there.
