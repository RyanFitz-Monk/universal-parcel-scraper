# Intigo

Intigo parcels use enabled universal providers. There is no dedicated adapter.

Intigo is a Tunisian courier for online sellers, with express delivery and cash on delivery, based
in Ariana.

## Numbers

Its tracker takes a parcel number or the recipient's phone number. No public page shows an Intigo
number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`intigo.net/?nid=<number>` is the link the site shares for a parcel, and the library reads the
number from that address.
