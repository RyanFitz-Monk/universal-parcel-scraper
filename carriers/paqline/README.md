# PAQLine

PAQLine parcels use enabled universal providers. There is no dedicated adapter.

PAQLine Express Group is a courier in Sangüesa, Navarra, for local, national and international
deliveries. Its IRIS tenant is named after the region.

## Numbers

No public page shows a PAQLine number, so there is no rule.

## Why there is no adapter

The tracker is the company's tenant of the IRIS courier software on `navarra.factapp.es`. It
posts an ASP.NET form, so a number cannot go in the address. No public number is known to check
its replies against.

## Links

The company's site links the tracker. The tracker takes numbers only in its form, so the catalog sends people to the tracking page.
