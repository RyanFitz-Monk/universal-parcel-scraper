# Kleine Spedition

Kleine Spedition parcels use enabled universal providers. There is no dedicated adapter.

Kleine Spedition GmbH, of Grevenbroich, is a family forwarder for national and European
groupage, transport, warehousing and contract logistics.

## Numbers

Its tracker takes a colli (package) number. No public page shows one, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`tt.kleine.eu/tracking/anon/anondetail.seam?colliScanNumber=<number>` opens one package, and
the library reads the number from `colliScanNumber`.
