# Ativa Logística

Ativa Logística parcels use enabled universal providers. There is no dedicated adapter.

Ativa Logística is a Brazilian logistics operator and carrier for pharmaceuticals, beauty and
wellness products, founded in 1996, with 27 units across Brazil.

## Numbers

The tracking form on its home page uses SSW, the freight system many Brazilian road carriers share,
and takes the recipient's, sender's or payer's CPF or CNPJ; a CNPJ also needs a password. It has no
field for an Ativa number, so there is no rule.

## Why there is no adapter

Every lookup needs a CPF or CNPJ.

## Links

Lookups need the tax id, so there are no tracking links.
