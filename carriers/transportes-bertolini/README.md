# Transportes Bertolini

Transportes Bertolini parcels use enabled universal providers. There is no dedicated adapter.

Transportes Bertolini (TBL), founded in Rio Grande do Sul, carries freight by road and on Amazon
river routes to and from Manaus, with warehousing, in 20 Brazilian states.

## Numbers

Its tracker takes an invoice (nota fiscal) number with a CNPJ. It has no field for a TBL number of
its own, so there is no rule.

## Why there is no adapter

Every lookup needs a CNPJ and a reCAPTCHA token.

## Links

Lookups need the tax id, so there are no tracking links.
