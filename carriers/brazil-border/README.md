# Brazil Border

Brazil Border parcels use enabled universal providers. There is no dedicated adapter.

Brazil Border is a cross-border shipping company that carries parcels bought abroad into Brazil and
clears them through customs.

## Numbers

No public page shows a Brazil Border number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The tracking form sends the number as `/rastreio/?code=<number>`, and the library reads it from that
address.
