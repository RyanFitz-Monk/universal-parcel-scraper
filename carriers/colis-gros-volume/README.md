# Colis Gros Volume

Colis Gros Volume parcels use enabled universal providers. There is no dedicated adapter.

Colis Gros Volume delivers bulky parcels and pallets, with a one-page public tracker. SARL AICA
Sanitaire of Limay runs it.

## Numbers

Its tracker takes a tracking number and gives no layout. No public page shows one, so there is
no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`colisgrosvolume.fr/?suivino=<number>` looks one parcel up, and the library reads the number
from `suivino`.
