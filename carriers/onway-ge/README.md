# OnWay

OnWay parcels use enabled universal providers. There is no dedicated adapter.

OnWay is a Georgian courier that delivers across the country.

## Numbers

Its tracker takes a tracking or order number, or a phone number with a code sent by SMS. No public
page shows an OnWay number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The search box on the home page posts the number and answers in place, so there are no tracking
links.
