# Aeropaq

Aeropaq parcels use enabled universal providers. There is no dedicated adapter.

Aeropaq is a Dominican courier that receives purchases abroad and delivers them through its
terminals across the Dominican Republic.

## Numbers

Its home page takes a tracking number. No public page shows an Aeropaq number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The tracking box looks the number up from the home page, so there are no tracking links.
