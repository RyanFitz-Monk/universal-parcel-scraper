# Koombiyo Delivery

Koombiyo Delivery parcels use enabled universal providers. There is no dedicated adapter.

Koombiyo Delivery is a Sri Lankan courier with more than a hundred branches across the island.

## Numbers

No public page shows a Koombiyo Delivery number, so there is no rule.

## Why there is no adapter

Its tracker asks for the order's phone number beside the waybill number. No public number is known
to check its tracker's replies against.

## Links

`koombiyodelivery.lk/track?id=<number>` opens the tracker with the number filled in, and the library
reads the number from that address. The phone number still has to be typed.
