# Tramaco Express

Tramaco Express parcels use enabled universal providers. There is no dedicated adapter.

Tramaco Express is an Ecuadorian courier and last-mile carrier based in Quito.

## Numbers

Its tracking page asks for a fifteen-digit guide number. No public page shows a real Tramaco number,
and fifteen digits are a shape many carriers share, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`/rastreo.html?guia=<number>` looks one guide up, and the library reads the number from that
address.
