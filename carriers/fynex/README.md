# FyNEX

FyNEX parcels use enabled universal providers. There is no dedicated adapter.

FyNEX (F Y N Express Couriers LLC) is a courier based in Al Qusais, Dubai. It delivers documents
and parcels within the UAE, the same day or later, to the other Gulf states and abroad, and delivers
for online shops. Its site is fynexcourierdubai.com.

## Numbers

Its tracking page takes a tracking number. No public page shows one, so there is no rule.

## Why there is no adapter

Its tracking page posts the number as `trackno` to itself and answers in the page. The site is TSS
Smart's courier build, like [MAX Express's](../max-express-ae/README.md). No public number is known
to check its replies against.

## Links

The tracker answers only by POST, so no address opens one shipment.
