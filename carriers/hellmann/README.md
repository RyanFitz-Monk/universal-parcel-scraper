# Hellmann Worldwide Logistics

Hellmann Worldwide Logistics parcels use enabled universal providers. There is no dedicated adapter.

Hellmann Worldwide Logistics, of Osnabrück, forwards air, sea, road and rail freight. Recipients
of its road groupage track packages by their NVE.

## Numbers

Its tracker takes a shipment number, or for road freight a package's NVE, which is an SSCC and
names whoever issued it. No public page shows a Hellmann shipment number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`public.tracking.hellmann.net/search/<number>` looks one shipment up, and the library reads the
number from that address.
