# Fast Express Cargo

Fast Express Cargo parcels use enabled universal providers. There is no dedicated adapter.

Fast Express Cargo Pvt. Ltd. is a courier and cargo company in Ludhiana, Punjab, with franchise
offices across North India. Its site is fastexpresscargo.com.

## Numbers

Its tracking form takes a tracking ID. No public page shows one, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The tracking form on `www.fastexpresscargo.com/tracking.html` opens
`lms.fastexpresscargo.com/WebTracking/WebTracking.aspx?AwbNo=<number>`, and the library reads the
number from `AwbNo`.
