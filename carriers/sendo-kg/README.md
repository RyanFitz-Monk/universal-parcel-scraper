# Sendo

Sendo parcels use enabled universal providers. There is no dedicated adapter.

Sendo is a courier in Bishkek, Kyrgyzstan.

## Numbers

No public page shows a Sendo number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`sendoexpress.net/tracking.html?code=<number>` looks one number up, and the library reads the number
from that address.
