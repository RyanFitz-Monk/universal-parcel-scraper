# Cargo International

Cargo International parcels use enabled universal providers. There is no dedicated adapter.

Cargo International GmbH, of Villingen-Schwenningen, is an online forwarder. Customers book
parcels, pallets and freight in Germany, Europe and worldwide, which partners move under
Cargo International's order numbers.

## Numbers

Its tracker takes an order number (Auftragsnummer). No public page shows one, so there is no
rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`cargointernational.de/versandrechner/tracking/<number>` opens one order, and the library reads
the number from that address.
