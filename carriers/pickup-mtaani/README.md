# Pickup Mtaani

Pickup Mtaani parcels use enabled universal providers. There is no dedicated adapter.

Pickup Mtaani is a Kenyan courier for online sellers, with a network of agent pickup points and
door-to-door delivery.

## Numbers

Its tracker takes a package code or tracking id. No public page shows a Pickup Mtaani number, so
there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`new.pickupmtaani.com/track-package?package=<number>` looks one package up, and the library reads
the number from that address.
