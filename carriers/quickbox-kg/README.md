# QuickBox

QuickBox parcels use enabled universal providers. There is no dedicated adapter.

QuickBox is a Kyrgyz courier that runs its own line from Guangzhou to Bishkek for online orders and
delivers them in Bishkek, Osh and other cities.

## Numbers

No public page shows a QuickBox number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The tracker posts the number and shows the answer on the same page, so there are no tracking links.
