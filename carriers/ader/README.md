# ADER

ADER parcels use enabled universal providers. There is no dedicated adapter.

ADER, run by Servicios Empresariales ADER, S.A. of L'Hospitalet de Llobregat, delivers furniture,
mattresses and appliances to homes with dedicated transport, and runs night and express
services.

## Numbers

Its order-status form takes an order number with the delivery postcode, and refers IKEA orders
to IKEA. No public page shows an order number, so there is no rule.

## Why there is no adapter

Every lookup needs the delivery postcode. No public number is known to check its tracker's
replies against.
