# Bauer Express

Bauer Express parcels use enabled universal providers. There is no dedicated adapter.

Bauer Express is a parcel and part-load carrier in Chapecó, Santa Catarina, part of Grupo Bauer,
that covers the whole of southern Brazil.

## Numbers

Its tracking page embeds the tracker of SSW, the freight system many Brazilian road carriers share.
It takes an invoice or order number with the sender's or recipient's CPF or CNPJ, or the invoice's
44-digit access key alone. Bauer Express has no number of its own there, so there is no rule.

## Why there is no adapter

Its lookups are SSW forms that need a tax id or the invoice's access key.

## Links

The forms post their fields, so there are no tracking links.
