# United Pallet Network

United Pallet Network parcels use enabled universal providers. There is no dedicated adapter.

United Pallet Network (UPN) is a UK pallet network of member depots around a central hub, with
next-day and two-day services across the UK, Ireland and Europe.

## Numbers

Its POD tracker takes a consignment number with the delivery postcode. No public page shows
one, so there is no rule.

## Why there is no adapter

Every lookup needs the delivery postcode. No public number is known to check its tracker's
replies against.
