# Expreso Marvisur

Expreso Marvisur parcels use enabled universal providers. There is no dedicated adapter.

Expreso Marvisur is a road freight and parcel carrier from Arequipa with more than a hundred
branches across Peru.

## Numbers

Its tracker takes the series and number of the carrier's electronic waybill (GRE) with the sender's
DNI, RUC or foreign ID. It has no field for a number alone, so there is no rule.

## Why there is no adapter

Every lookup needs the sender's ID document.

## Links

Lookups need the ID document, so there are no tracking links.
