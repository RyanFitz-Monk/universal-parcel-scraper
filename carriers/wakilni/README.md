# Wakilni

Wakilni parcels use enabled universal providers. There is no dedicated adapter.

Wakilni is a Beirut courier for online shops and businesses that delivers across Lebanon.

## Numbers

Its tracker takes an order number of at least five letters and digits. No public page shows a
Wakilni number, so there is no rule.

## Why there is no adapter

The tracking box on its home page carries a Google reCAPTCHA before it opens the order page. No
public number is known to check its tracker's replies against.

## Links

`portal.wakilni.com/orders/<number>` opens one order, and the library reads the number from that
address.
