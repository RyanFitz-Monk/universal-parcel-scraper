# Uello

Uello parcels use enabled universal providers. There is no dedicated adapter.

Uello is a São Paulo company that runs last-mile deliveries with its own courier app and sells
delivery-management software.

## Numbers

Its order lookup takes the recipient's CPF or CNPJ and lists that person's orders of the last thirty
days. Its detailed tracker takes a shipment or invoice number only beside the tax id. No public page
shows a Uello number, so there is no rule.

## Why there is no adapter

Every lookup needs a CPF or CNPJ.

## Links

Lookups need the tax id, and the links shippers send carry an opaque key, so there are no
tracking links.
