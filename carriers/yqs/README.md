# YQS Logistics

YQS Logistics parcels use enabled universal providers. There is no dedicated adapter.

YQS Logistics (悦其胜, 深圳市悦其胜物流有限公司), trading as 天凡国际物流, is a Shenzhen air line from
China to Mexico, duties paid, with Mexican last-mile delivery. Its site yqslogistics.com serves
plain HTTP only; its tracker is its tenant page on the NextSLS forwarder platform.

## Numbers

No public page shows a YQS number, so there is no rule.

## Why there is no adapter

No public number is known to check the tracker's replies against.

## Links

The tenant page reads numbers from its `numbers` parameter beside its `app` id. Other forwarders
share the NextSLS host, so only links with YQS's `app` id are read.
