# Nepal Can Move

Nepal Can Move parcels use enabled universal providers. There is no dedicated adapter.

Nepal Can Move is a courier in Kathmandu that delivers across Nepal and collects cash on delivery.

## Numbers

No public page shows a Nepal Can Move number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The tracker posts the number and shows the answer on the same page, so there are no tracking links.
