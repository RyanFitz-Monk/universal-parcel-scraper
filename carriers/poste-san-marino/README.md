# Poste San Marino

Poste San Marino parcels use enabled universal providers. There is no dedicated adapter.

Poste San Marino S.p.A., of Serravalle, is the national post of San Marino.

## Numbers

No public page shows a Poste San Marino number, so there is no rule.

## Why there is no adapter

Its tracker checks each lookup with Google reCAPTCHA v3 and opens the result with the check's
token, so no address opens an item from its number alone. No public number is known to check
its tracker's replies against.
