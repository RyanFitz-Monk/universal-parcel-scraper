# PML

PML shipments use enabled universal providers. There is no dedicated adapter.

PML (遠達國際) is a Taiwanese forwarder and travel agency, founded in 1981, handling
international express, air, sea and land freight, customs clearance and logistics.

## Numbers

Its PML shipment search takes one or more express waybill numbers in a text box. No public page
shows one, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The search posts the numbers as `AWBNo` to `www.pml-intl.com/PML/pc/search/listpod.asp` and
answers only by POST, so no address opens one shipment. The same page links the TNT, Sagawa and
EMS trackers.
