# LiteXpress

LiteXpress parcels use enabled universal providers. There is no dedicated adapter.

LiteXpress International Inc. is a Philippine courier and forwarder with its head office in Cubao,
Quezon City, and branches across the country. Its site is litexpress.com.ph.

## Numbers

Its Track and Trace page takes a tracking number. No public page shows one, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Leads

The Track and Trace page's script looks the number up with
`GET https://litexpress.com.ph/proxy.php?tracking=<number>`, which answers JSON.

## Links

The Track and Trace page reads no number from its address, so there are no tracking links.
