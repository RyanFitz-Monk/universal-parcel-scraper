# GBS

GBS parcels use enabled universal providers. There is no dedicated adapter.

GBS (ГБС-Брокер) of Moscow is a customs representative and cross-border express operator with
seven bonded warehouses. It brings online shops' parcels, express cargo and samples into Russia
from China, Hong Kong, Turkey, the United Arab Emirates and India. Its tracker shows a parcel's
customs and warehouse stages; after customs release, GBS hands the parcel to the carrier the
sender chose, which delivers it.

## Numbers

Its tracker takes one number, or several separated by commas. No public page shows one, so there
is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`gbs.ru/track/?numbers=<number>` looks the number up, and the library reads the number from
`numbers`, the first one when the address lists several.
