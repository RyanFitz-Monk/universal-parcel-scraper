# Fixtures

These synthetic pages retain the guest form, identity card, scan columns and lookup notices.
Identifiers, clocks and places are invented. The New Year crossing checks that yearless clocks
remain as displayed and retain the carrier's order. The current-scan badge is presentation only.

The mobile JSON fixture is the same confirmed public sender-export sample from [Scribd](https://fr.scribd.com/document/976873304/Exportation-Paiement-Pmt-N54CSF), retrieved through the official app guest endpoint. Its whole identifier is replaced with a synthetic value. Full `datetime` fields are facility clocks without offsets.
