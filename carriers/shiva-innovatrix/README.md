# SHIVA

SHIVA parcels use enabled universal providers. There is no dedicated adapter.

SHIVA INNOVATRIX handles cross-border e-commerce shipping, customs clearance, warehousing and air
and ocean freight into and out of Korea.

## Numbers

Its Track & Trace page asks for eleven or twelve digits. No public page shows one, so there is no
rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Leads

The page's script reads `www.shivaicl.net/api/tracking-api/query/<number>` with a key the page
gives every visitor in an `x-api-key` header.

## Links

The page takes the number only in its form, so no address opens one shipment.
