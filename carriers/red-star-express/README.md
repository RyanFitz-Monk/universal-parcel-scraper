# Red Star Express

Red Star Express parcels use enabled universal providers. There is no dedicated adapter.

Red Star Express is a listed Nigerian courier based in Lagos. It is FedEx's licensee in Nigeria.

## Numbers

No public page shows a Red Star Express number, so there is no rule. Its international shipments
carry FedEx numbers, which [FedEx](../fedex/README.md) tracks.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The tracker posts one or more numbers and answers on the same page, so there are no tracking links.
