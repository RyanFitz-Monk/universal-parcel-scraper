# MAX Express

MAX Express parcels use enabled universal providers. There is no dedicated adapter.

MAX Express Courier Services is a courier based in Al Qusais, Dubai. It collects and delivers
documents and parcels within the UAE, including same-day, cash-on-delivery and cheque collection
work, and sends shipments abroad. Its site is maxexuae.com.

## Numbers

Its tracking page takes a tracking, reference or booking number, and the box on its home page an
air waybill number. No public page shows one, so there is no rule.

## Why there is no adapter

Its tracking page posts the number as `trackno` to itself and answers in the page. The site is TSS
Smart's courier build, like [FyNEX's](../fynex/README.md). No public number is known to check its
replies against.

## Links

The tracker answers only by POST, so no address opens one shipment.
