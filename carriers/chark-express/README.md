# Chark Express

Chark Express parcels use enabled universal providers. There is no dedicated adapter.

Chark Express is a Moroccan courier for online sellers that collects, delivers and takes cash on
delivery.

## Numbers

No public page shows a Chark Express number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The tracking form on the home page posts the parcel code and shows the answer in place, so there are
no tracking links.
