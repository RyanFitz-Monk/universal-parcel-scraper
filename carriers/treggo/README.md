# Treggo

Treggo parcels use enabled universal providers. There is no dedicated adapter.

Treggo is a same-day and last-mile courier for online shops, based in Buenos Aires, with sites for
Colombia, Mexico and Uruguay that serve the same tracker.

## Numbers

Its tracker takes the shop's order number or the buyer's email address. No public page shows a
Treggo number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The tracking form posts its field, so there are no tracking links.
