# Palletforce

Palletforce parcels use enabled universal providers. There is no dedicated adapter.

Palletforce, part of EV Cargo, is a pallet network of over a hundred member hauliers around a
central hub in Burton-on-Trent.

## Numbers

Its tracker takes a tracking number, consignment number or customer reference with the
delivery postcode. No public page shows one, so there is no rule.

## Why there is no adapter

Every lookup needs the delivery postcode, and the tracker only answers a posted form. No public
number is known to check its tracker's replies against.
