# Tupaq Courier

Tupaq Courier parcels use enabled universal providers. There is no dedicated adapter.

Tupaq Courier is a Dominican courier that receives purchases at an address in Miami and delivers
them in the Dominican Republic.

## Numbers

No public page shows a Tupaq number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The site opens `app.iplus.com.do/tupaq/fe/lg-es/ut/Estatus.aspx?id=<number>`, a page on the iPlus
courier platform, and the library reads the number from that address.
