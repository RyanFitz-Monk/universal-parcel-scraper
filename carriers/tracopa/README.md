# Tracopa

Tracopa parcels use enabled universal providers. There is no dedicated adapter.

Tracopa is a bus company serving southern Costa Rica and David in Panama. Its parcel service carries
shipments on those lines.

## Numbers

Its tracker takes a guide number of digits. No public page shows a Tracopa number, so there is no
rule.

## Why there is no adapter

The tracker asks for a reCAPTCHA checkbox before it looks a number up.

## Links

The tracking form posts its field, so there are no tracking links.
