# Gaaubesi

Gaaubesi parcels use enabled universal providers. There is no dedicated adapter.

Gaaubesi is a Nepali delivery company for online sellers.

## Numbers

Its tracker takes an order tracking id of up to fifteen letters and digits, often written in groups
with hyphens. No public page shows a Gaaubesi number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`delivery.gaaubesi.com/orders/track-order/?track_id=<number>` looks one order up, and the library
reads the number from that address.
