# MNPOST

MNPOST parcels use enabled universal providers. There is no dedicated adapter.

MNPOST carries online orders and personal parcels from China to Mongolia.

## Numbers

Its home page describes its codes as two letters and ten digits. No public page shows an MNPOST
number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`mnpost.mn/tracking?nums=<number>` looks one number up, and the library reads the number from that
address.
