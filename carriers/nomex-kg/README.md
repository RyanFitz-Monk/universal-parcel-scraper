# Nomex

Nomex parcels use enabled universal providers. There is no dedicated adapter.

Nomex is a courier in Bishkek, Kyrgyzstan.

## Numbers

No public page shows a Nomex number, so there is no rule.

## Why there is no adapter

Its tracker is a widget of the iShip courier platform. No public number is known to check its
tracker's replies against.

## Links

`nomex.kg/?iShip_Invoice=<number>` looks one number up, and the library reads the number from that
address.
