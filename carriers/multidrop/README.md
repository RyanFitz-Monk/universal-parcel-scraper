# Multidrop

Multidrop parcels use enabled universal providers. There is no dedicated adapter.

Multidrop is the recipient tracker of Multidrop Assist, home delivery software by GSiT of
Darlington. Delivery firms and retailers that run their own deliveries on it send recipients to
multidrop.link.

## Numbers

The tracker takes a tracking reference with the delivery postcode. No public page shows a
reference, so there is no rule.

## Why there is no adapter

Every lookup needs the delivery postcode. No public number is known to check its tracker's
replies against.
