# Expressgodo Logistics

Expressgodo Logistics parcels use enabled universal providers. There is no dedicated adapter.

Expressgodo Logistics is a truckload carrier in Franklin Park, Illinois, with its own trucks and
trailers. It runs truckload, team and expedited services across the 48 contiguous states.

## Numbers

Its tracker takes an order number. No public page shows one, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`expressgodo.com/track.php?order_track=<number>` opens one order, and the library reads the
number from `order_track`.
