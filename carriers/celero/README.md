# Celero

Celero parcels use enabled universal providers. There is no dedicated adapter.

Celero is a Mauritian freight forwarder, shipping agent and express courier that also works in
Madagascar.

## Numbers

Its tracker takes up to fifty numbers at once. No public page shows a Celero number, so there is no
rule.

## Why there is no adapter

The tracking form on its home page carries a Cloudflare Turnstile check. No public number is known
to check its tracker's replies against.

## Links

The tracking form posts its numbers and shows the answer on the same page, so there are no tracking
links.
