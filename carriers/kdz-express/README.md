# KDZ Express

KDZ Express parcels use enabled universal providers. There is no dedicated adapter.

KDZ Express B.V., at Schiphol Airport, carries express parcels, documents and pallets worldwide by
air and road.

## Numbers

Its tracker takes a shipment number. No public page shows one, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`kdz.com/track-trace/?nr=<number>` fills the number in and looks it up, also under a language
prefix such as `/nl/`, and the library reads the number from `nr`.
