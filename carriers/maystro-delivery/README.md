# Maystro Delivery

Maystro Delivery parcels use enabled universal providers. There is no dedicated adapter.

Maystro Delivery is an Algerian delivery and fulfilment company for online shops, with hubs in
Algiers and drivers across the country.

## Numbers

No public page shows a Maystro Delivery number, so there is no rule.

## Why there is no adapter

Its tracker asks for the recipient's phone number beside the tracking number, and runs reCAPTCHA
Enterprise before each lookup. No public number is known to check its tracker's replies against.

## Links

The tracker takes the number in a form, so there are no tracking links.
