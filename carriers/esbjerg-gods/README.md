# Esbjerg Gods

Esbjerg Gods parcels use enabled universal providers. There is no dedicated adapter.

Esbjerg Gods is a Danish carrier with terminals in Esbjerg and Ringsted and vehicles across Denmark.
It runs fixed shuttle distribution of general cargo, part and full loads, courier and terminal
services.

## Numbers

No public page shows an Esbjerg Gods number, so there is no rule.

## Why there is no adapter

The tracker is Esbjerg Gods' page in AliceTMS, an AngularJS app at `t.alicetms.dk` that posts the
company and the number to `/TrackAndTrace/Trace`. No public number is known to check its replies
against.

## Links

The Standard Tracking form in the site's header opens
`t.alicetms.dk/#/Esbjerg-gods/TrackAndTrace/<number>`. Shipments on Zealand use a second AliceTMS
company, Esbjerg Gods Sjælland, which the header's Sjælland Tracking form opens; the catalog opens the
main one. The AliceTMS page has no search box, so the catalog's search page is the carrier's site.
