# Urbano Argentina

Urbano Argentina parcels use enabled universal providers. There is no dedicated adapter.

Urbano Argentina is a courier and e-commerce delivery company in Buenos Aires. It has its own
tracker and numbers, apart from [Urbano](../urbano/README.md) in Peru and Ecuador.

## Numbers

Its tracking page asks for fifteen digits, the first four naming the shipper. No public page shows
an Urbano Argentina number, and fifteen digits are a shape many carriers share, so there is no rule.

## Why there is no adapter

The tracking page shows a reCAPTCHA. No public number is known to check its tracker's replies
against.

## Links

The page splits the number into the shipper's code and the rest before it looks it up, so there is
no tracking link for one number.
