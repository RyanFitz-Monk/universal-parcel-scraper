# Breaze

Breaze parcels use enabled universal providers. There is no dedicated adapter.

Breaze is a South African same-day courier for online shops, delivering in Gauteng and Cape Town.

## Numbers

Its tracker takes a waybill or job number. No public page shows a Breaze number, so there is no
rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`portal.breaze.co.za/track-order/<number>` opens one order, and the library reads the number from
that address.
