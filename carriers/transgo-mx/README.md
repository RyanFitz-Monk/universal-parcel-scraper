# TransGo

TransGo parcels use enabled universal providers. There is no dedicated adapter.

Trans Go Bajío, S.A. de C.V., of León, Guanajuato, distributes goods across Mexico: parcels, part
and full loads, critical shipments and storage.

## Numbers

No public page shows a TransGo guide, so there is no rule.

## Why there is no adapter

The home page's tracking form asks `GET api.transgo.mx/tracking/<guide>`. No public guide is known
to check its replies against.

## Links

The form reads no guide from the page's address, so the catalog sends people to the home page.
