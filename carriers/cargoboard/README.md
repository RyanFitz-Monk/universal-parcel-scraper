# Cargoboard

Cargoboard parcels use enabled universal providers. There is no dedicated adapter.

Cargoboard GmbH & Co. KG, of Paderborn, is a digital freight forwarder for groupage, part and
full loads in Germany and Europe.

## Numbers

Its tracker takes a shipment number with the consignee's postcode. No public page shows one, so
there is no rule.

## Why there is no adapter

Every lookup needs the consignee's postcode. No public number is known to check its tracker's
replies against.
