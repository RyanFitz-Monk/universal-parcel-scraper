# Meyer-Jumbo

Meyer-Jumbo parcels use enabled universal providers. There is no dedicated adapter.

MEYER-JUMBO Logistics, of Porta Westfalica, is a forwarder for transport, international shipping,
warehousing and dangerous goods. Its tracker for recipients also takes a permission to leave the
delivery.

## Numbers

The tracker takes a shipment number of 20 characters. No public page shows one, so there is no
rule.

## Why there is no adapter

The tracker only answers a posted form, so no address opens a shipment. No public number is
known to check its tracker's replies against.
