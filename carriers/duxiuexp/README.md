# DuXiuExp

DuXiuExp parcels use enabled universal providers. There is no dedicated adapter.

DuXiuExp (独秀国际) is a Shanghai export forwarder: air freight, international express,
Amazon FBA deliveries, China–Europe road and rail, and dedicated lines to North America, Europe,
Oceania, Asia, Africa and the Middle East.

## Numbers

No public page shows a DuXiuExp number, so there is no rule.

## Why there is no adapter

No public number is known to check the tracker's replies against.

## Links

The tracking form opens `/S/<number>`, with several numbers joined by commas.
