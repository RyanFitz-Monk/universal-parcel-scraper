# Liftit

Liftit parcels use enabled universal providers. There is no dedicated adapter.

Liftit is a delivery company from Bogotá whose own drivers carry first-, middle- and last-mile loads
for shops and manufacturers.

## Numbers

Its tracker takes task and order codes. No public page shows a Liftit number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`tracking.liftit.co/<number>` opens one shipment, and the library reads the number from that
address. Addresses that hold an internal id with dashes are left alone.
