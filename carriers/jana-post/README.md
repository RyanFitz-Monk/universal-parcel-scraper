# Jańa Post

Jańa Post parcels use enabled universal providers. There is no dedicated adapter.

Jańa Post is a Kazakh delivery company for marketplace orders, with more than a thousand branches
across Central Asia.

## Numbers

No public page shows a Jańa Post number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`janapost.kz/en/track-order?code=<number>` looks one number up (also under its other languages), and
the library reads the number from that address.
