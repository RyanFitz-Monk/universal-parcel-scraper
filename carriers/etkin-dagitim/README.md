# Etkin Dağıtım

Etkin Dağıtım parcels use enabled universal providers. There is no dedicated adapter.

Etkin Dağıtım is an Istanbul distributor licensed by BTK that delivers signed mail and bulk mail
such as statements and inserts for companies.

## Numbers

The tracker takes a barcode of up to 12 characters. No public page shows one, so there is no rule.

## Why there is no adapter

The tracking page posts the barcode to `barkod_grapor.asp`; its other forms search by subscriber
number or need a customer login.

## Links

The tracker takes numbers only in its form, so the catalog sends people to the tracking page.
