# Logística Alatec

Logística Alatec parcels use enabled universal providers. There is no dedicated adapter.

Logística Alatec is a courier in A Coruña for local and national parcels, delivered with its own
vehicles and through the [GLS](../gls-es/README.md) and [CTT Express](../ctt-express/README.md)
networks.

## Numbers

No public page shows a Logística Alatec number, so there is no rule.

## Why there is no adapter

The tracker is the company's tenant of the IRIS courier software on `logisticaalatec.factapp.es`. It
posts an ASP.NET form, so a number cannot go in the address. No public number is known to check
its replies against.

## Links

The company's site links the tracker. The tracker takes numbers only in its form, so the catalog sends people to the tracking page.
