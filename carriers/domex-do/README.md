# Domex Expreso

Domex Expreso parcels use enabled universal providers. There is no dedicated adapter.

Domex Expreso is a Dominican courier with more than seventy offices and lockers. It also receives
purchases at addresses in Miami and Madrid. It is a different company from Sri Lanka's
[Domex](../domex/README.md).

## Numbers

Its tracker takes a Domex guide or the shop's tracking number. No public page shows a Domex Expreso
number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`domex.do/rastreo?guia=<number>` looks one number up, and the library reads the number from that
address.
