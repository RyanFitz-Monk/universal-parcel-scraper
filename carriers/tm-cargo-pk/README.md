# TM Cargo

TM Cargo parcels use enabled universal providers. There is no dedicated adapter.

TM Cargo is a road freight, cargo and courier company in Karachi with offices in Lahore and
Islamabad.

## Numbers

Its tracker takes a CN number. No public page shows a TM Cargo number, so there is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`tmcargo.net/track.php?cn=<number>` looks one number up, and the library reads the number from that
address.
