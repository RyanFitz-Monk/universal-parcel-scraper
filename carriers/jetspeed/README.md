# JETSPEED

JETSPEED (捷速达国际快运) is a Shenzhen forwarder. Its parcels use enabled universal providers;
there is no dedicated adapter.

## Numbers

A parcel to Spain carried JSD and twelve digits. A low rule offers JETSPEED for that shape.

## Why there is no adapter

The tracker at `www.jetspeed-express.com/search_kuai_di/search/orderid/{number}` renders the
scans on the server as a table of wall clocks and wordings, without the zones of clocks read in
China and at the destination, and its answer names the number only in the prefilled search
box. Universal providers relay the same scans.

## Links

The tracker's address carries the number in its path, and is read as a link.
