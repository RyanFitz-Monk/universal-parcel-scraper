# CN Express

CN Express parcels use enabled universal providers. There is no dedicated adapter.

CN Express is a cross-border express service from China to South Africa, run by a logistics company
in Shanghai. It carries online orders, Temu's among them, to South African buyers.

## Numbers

Its tracker's example is CN and thirteen digits. No public page shows a CN Express number, so there
is no rule.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

`cnexpressintl.com/service_support/track?order_no=<number>` looks one number up, and the library
reads the number from that address.
