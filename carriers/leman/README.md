# LEMAN

LEMAN parcels use enabled universal providers. There is no dedicated adapter.

LEMAN is a Danish transport and logistics company headquartered in Greve. It runs road, air, sea,
rail, express and project transport, and warehousing.

## Numbers

The tracker asks for a booking number. No public page shows a LEMAN number, so there is no rule.

## Why there is no adapter

The tracker at `track.leman.com`, also served at `track.yourleman.com`, is a Blazor Server app that
searches over its live connection. No public number is known to check its replies against.

## Links

The tracker takes numbers only in its form, so the catalog sends people to the tracking page.
