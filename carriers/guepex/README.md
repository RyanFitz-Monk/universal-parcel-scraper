# Guepex

Guepex parcels use enabled universal providers. There is no dedicated adapter.

Guepex is an Algerian courier with express and economy delivery and cash on delivery, through
agencies across the country's provinces.

## Numbers

Its tracker's example starts with `YAL-`, the prefix of [Yalidine](../yalidine/README.md)'s numbers,
which detection gives to Yalidine. No public page shows a Guepex number, so there is no rule.

## Why there is no adapter

The tracker asks for a reCAPTCHA checkbox before it looks a number up. No public number is known to
check its tracker's replies against.

## Links

The tracking form posts the number with its reCAPTCHA answer, so there are no tracking links.
