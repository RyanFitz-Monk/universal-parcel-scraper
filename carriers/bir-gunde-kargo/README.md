# Bir Günde Kargo

Bir Günde Kargo parcels use enabled universal providers. There is no dedicated adapter.

Bir Günde Kargo is a Turkish parcel carrier based in Kağıthane, Istanbul, licensed by BTK. It
delivers e-commerce parcels, appointment and chilled deliveries through branches and agencies
across Turkey.

## Numbers

No public page shows a Bir Günde Kargo number, so there is no rule.

## Why there is no adapter

The tracking form on the home page asks for an image code beside the number, posts both to
`KargoApi/Gonder` and opens the result address it gets back.

## Links

The tracker takes numbers only in its form, so the catalog sends people to the home page.
