# Rapiboy

Rapiboy parcels use enabled universal providers. There is no dedicated adapter.

Rapiboy is a same-day courier with its own riders, based in Buenos Aires. Its delivery service for
online shops is called Rapilog.

## Numbers

Its tracker takes the shipment's reference. No public page shows a Rapiboy number, so there is no
rule.

## Why there is no adapter

The tracker asks for a reCAPTCHA checkbox before it looks a number up.

## Links

The tracker posts the reference and opens a page under an id its server returns, so there are no
tracking links.
