# Paquexpress Urgente

Paquexpress Urgente parcels use enabled universal providers. There is no dedicated adapter.

Paquexpress Urgente is a courier in Toledo for urgent business and home deliveries, with storage
and logistics services. It is not Mexico's [Paquetexpress](../paquetexpress/README.md).

## Numbers

No public page shows a Paquexpress Urgente number, so there is no rule.

## Why there is no adapter

The tracker is the IRIS courier software on the company's own domain. It posts an ASP.NET form,
so a number cannot go in the address. No public number is known to check its replies against.

## Links

The tracker takes numbers only in its form, so the catalog sends people to the tracking page.
