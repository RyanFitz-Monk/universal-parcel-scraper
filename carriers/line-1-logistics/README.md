# Line-1 Logistics

Line-1 Logistics shipments use enabled universal providers. There is no dedicated adapter.

Line-1 Logistics is a licensed customs broker and freight forwarder in Perth, Western Australia. It
clears imports and moves sea and air freight, with warehousing and service in English and Chinese.
Its site is line-1.com.au.

## Numbers

Its Air Cargo Tracking page takes tracking numbers, one per line. No public page shows one, so
there is no rule.

## Why there is no adapter

The page asks `air.line-1.com/api/track` for each number, given as `no`, and shows the JSON reply.
No public number is known to check its replies against.

## Links

The page reads numbers only from its text box, so no address opens one shipment.
