# Georgian Post

Georgian Post parcels use enabled universal providers. There is no dedicated adapter.

Georgian Post is Georgia's national post.

## Numbers

It gives international items UPU S10 numbers ending in `GE`. Generic postal detection handles these
numbers, so no rule for Georgian Post claims them.

## Why there is no adapter

No public number is known to check its tracker's replies against.

## Links

The tracking box on the home page shows the answer in a pop-up. The address it loads returns an
unstyled fragment, so there are no tracking links.
