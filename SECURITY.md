# Security

## Reporting

Report vulnerabilities privately through
[GitHub security advisories](https://github.com/plhery/universal-parcel-scraper/security/advisories/new).
Include a reproduction and the affected version. The advisory is private, so the reproduction
can use one of your own parcels. Keep secrets out of public issues.

## Running it

The HTTP API binds to localhost by default. Before sharing it, configure a bearer token and
your proxy's own request limits. Your users' capability links and destination postcodes open
their parcels, so treat them as credentials. Keep TRAWL on a private network, and keep
dependencies and browser images current.
